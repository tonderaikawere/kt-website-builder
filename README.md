# KT Website Builder

KT Website Builder is a powerful, visual drag-and-drop website editor and designer. It operates local-first, allowing creators to visually structure sections, inspect styles, configure dynamic typography fonts, write custom CSS stylesheets, edit page SEO meta-tags, and export static HTML/CSS files instantly.

## 🚀 Key Features

- **Drag and Drop Canvas**: Instantly re-order, insert, and delete structural sections (Header, Hero, Features, CTA, Pricing, Testimonials, Contact Form, Social Links, and custom YouTube embed blocks).
- **Style Inspector**: Adjust colors, text alignments, borders, padding, margins, and border-radius settings visually in real-time.
- **Dynamic Google Fonts**: Choose typography families and load stylesheets dynamically.
- **Floating Rich Text Editor**: Format paragraphs with inline formatting options like Bold, Italic, Underline, and clear-formatting.
- **Responsive Simulator Bezel**: Simulate rendering viewports for Desktop, Tablet, and Mobile devices with bezel outlines.
- **Export Options**: Export self-contained HTML/CSS source code files or download/upload raw JSON project state configurations.
- **Autosave & History**: Tracks change logs dynamically for full undo/redo state restoration, and autosaves state to localStorage.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation & Development

1. Clone the repository:
   ```bash
   git clone https://github.com/tonderaikawere/kt-website-builder.git
   cd kt-website-builder
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
